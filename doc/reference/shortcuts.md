# Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+Space` | Open the workflow-node search dialog. |
| `Ctrl+Z` or `Cmd+Z` | Undo the most recent workflow edit. |
| `Ctrl+Shift+Z`, `Cmd+Shift+Z`, or `Ctrl+Y` | Redo the next workflow edit. |

Undo and redo cover workflow-node additions, deletions, renames, connections,
parameter edits, and drag-stop position changes, including edits made inside a
nested workflow. Restoring history returns to the root workflow and clears
cached execution results so displayed values always match the restored graph.

Use the DockView panel controls to focus and arrange the application workspace.
